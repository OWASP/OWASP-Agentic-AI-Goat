## Polling status

Application WebSockets remain retired. The synchronized implementation adds
bounded reconciliation timeouts, retryable revision initialization, a visible
retry cap, abort propagation, legacy mutation coverage, stale-response guards,
and stronger cross-database reset handling. SecureShop and the CSRF lab retain
their intentional HTTP/SSE transports; those are not workshop WebSockets.
