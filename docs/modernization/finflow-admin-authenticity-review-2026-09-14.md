A pure path calculation reproduces the issue without reading any file: with example base `/isolated-example/server`, the suffix of virtual `/var/app/../../outside` resolves through `path.join` to `/outside`. This demonstrates an application/host boundary defect in the mapping; it does not require removing traversal as a teaching technique. The replacement must allow intended virtual traversal only within the isolated lab target.
