# Community expectations

Treat contributors and learners respectfully. Give actionable technical feedback, welcome different experience levels, and credit others' work. Harassment, discriminatory language, threats, doxxing and publishing another person's private information are not acceptable.

These expectations apply to project issues, pull requests and other project-managed discussion. Maintainers may remove inappropriate content or restrict participation, with an explanation when safe and appropriate. To report misconduct privately, contact the project maintainer through the contact information on [their GitHub profile](https://github.com/hackerabhinavverma); do not publish private details in an issue. This document does not promise a response deadline or override OWASP-wide policies.
