# SecureShop bundled font licenses

The SecureShop interface self-hosts these pinned Fontsource packages. Each is
licensed under the SIL Open Font License 1.1. Exact copies of the package
license files ship with the standalone frontend build at the paths shown.

| Family | Package | Version | Axes used | Shipped license file |
|---|---|---:|---|---|
| Fraunces | `@fontsource-variable/fraunces` | 5.3.0 | `opsz`, `wght` | `/font-licenses/fraunces-OFL.txt` |
| Inter | `@fontsource-variable/inter` | 5.3.0 | `wght` | `/font-licenses/inter-OFL.txt` |
| JetBrains Mono | `@fontsource-variable/jetbrains-mono` | 5.3.0 | `wght` | `/font-licenses/jetbrains-mono-OFL.txt` |

Upstream attribution is preserved in each package's `metadata.json`.
